## Recommended 5-7 minute flow

1. Consumer mobile
   Open the mobile app, allow foreground location, show nearby producers on the map, open one provider detail page, and tap Navigate.

2. Consumer favorites
   Favorite a provider from the card or detail screen, then open Favorites to confirm it appears there.

3. Provider dashboard
   Sign in as the seeded provider, show the dashboard checklist and analytics summary, then update one opening-hours row.

4. Provider offers
   Create or update a Fresh Today offer so the provider portal demonstrates promotional content management.

5. Admin claims
   Sign in as admin, open Claim Requests, and approve one pending request.

6. Admin provider moderation
   Open a provider detail or moderation list and toggle verification or provider status.

7. Admin offer moderation
   Open Offer Moderation and archive one outdated post.

## Backup paths

- If location is unavailable in the mobile demo, use the seeded Favorites flow and provider detail screen instead of live nearby discovery.
- If claim approval is already consumed in the demo environment, show a rejected or pending claim detail and explain the moderation workflow.
- If opening-hours edits should stay unchanged, demonstrate category editing instead.
